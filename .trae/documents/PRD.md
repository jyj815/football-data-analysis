# 足球数据分析模型 - 产品需求文档

## 1. 产品概述

移动端足球比赛数据分析工具，专注于凯利值分析、赔率变化追踪和支持率趋势监测。通过直观的可视化图表，帮助用户快速分析比赛数据，辅助投注决策。

### 核心价值
- 实时追踪凯利值变化，发现市场异常
- 可视化赔率波动趋势
- 监控支持率动态变化
- 简洁直观的移动端交互体验

---

## 2. 功能模块

### 2.1 核心功能

#### 2.1.1 比赛列表模块
- 显示今日/明日比赛赛程
- 支持筛选：全部、已结束、进行中
- 快速查看比赛基本信息（主队、客队、比赛时间）
- 颜色标记重要比赛（热门、大热、异常赔率）

#### 2.1.2 凯利值分析模块
- **凯利值计算**：根据赔率计算理论概率和凯利指数
- **凯利趋势图**：展示凯利值随时间变化曲线
- **凯利指数分布**：显示主胜、平局、客胜的凯利值对比
- **市场异常预警**：高亮显示凯利值过高或过低的选项

**凯利值计算公式**：
```
凯利指数 = (赔率 × 支持率) / 100
理论概率 = 1 / 赔率 × 100
价值投注 = 凯利指数 > 1 时提示
```

#### 2.1.3 赔率分析模块
- **赔率走势图**：折线图展示赔率随时间变化
- **赔率对比表**：初盘 vs 即时赔率对比
- **赔率波动率**：计算赔率变化的百分比
- **多家公司赔率**：支持切换查看不同博彩公司赔率

#### 2.1.4 支持率分析模块
- **支持率分布图**：饼图/柱状图展示三方支持率
- **支持率变化趋势**：时间序列展示支持率变化
- **大单追踪**：显示支持率异常变化
- **冷热指数**：直观展示投注冷热程度

#### 2.1.5 比赛详情页
- 完整的凯利值、赔率、支持率数据
- 多维度图表分析
- 数据导出功能

### 2.2 辅助功能

#### 2.2.1 数据刷新
- 下拉刷新获取最新数据
- 自动定时刷新（可选）
- 最后更新时间显示

#### 2.2.2 收藏功能
- 收藏感兴趣的比赛
- 收藏列表快速访问

## 3. 用户界面设计

### 3.1 设计风格
- **主题**：深色体育风格，护眼且专业
- **主色调**：深蓝背景 (#0a1628)，配合荧光绿 (#00ff88) 强调色
- **卡片设计**：圆角卡片，毛玻璃效果
- **字体**：思源黑体 (Noto Sans SC)，数字使用等宽字体

### 3.2 色彩系统
```
--bg-primary: #0a1628      // 深蓝主背景
--bg-secondary: #152238    // 卡片背景
--bg-tertiary: #1e3054     // 悬浮/高亮背景
--accent-green: #00ff88    // 主强调色（涨/热）
--accent-red: #ff4757      // 副强调色（跌/冷）
--accent-yellow: #ffd93d   // 警示色
--text-primary: #ffffff    // 主文字
--text-secondary: #8b9dc3  // 次要文字
--text-muted: #5a6a8a      // 辅助文字
```

### 3.3 布局结构
- **顶部导航栏**：页面标题、刷新按钮、设置入口
- **Tab 切换**：凯利值 | 赔率 | 支持率 | 详情
- **内容区域**：可滚动的数据展示区
- **底部操作栏**：快捷筛选、数据刷新

### 3.4 响应式设计
- 针对手机屏幕优化（375px - 428px）
- 大按钮易触摸（最小 44px）
- 图表自适应屏幕宽度
- 横屏支持数据分析页面

## 4. 核心交互

### 4.1 比赛选择流程
1. 用户打开应用 → 显示比赛列表
2. 点击比赛卡片 → 进入分析详情页
3. Tab 切换查看不同维度数据

### 4.2 数据查看交互
- 左右滑动切换比赛
- 下拉刷新数据
- 点击图表查看详细数值
- 长按数据点显示tooltip

### 4.3 异常提醒交互
- 凯利值 > 1 时显示绿色边框
- 赔率突变时显示红点标记
- 支持率大幅变化时震动提示

## 5. 技术指标

### 5.1 性能要求
- 首屏加载 < 2秒
- 图表渲染流畅 (60fps)
- 数据更新延迟 < 5秒

### 5.2 兼容性
- iOS Safari 14+
- Android Chrome 90+
- 微信内置浏览器

### 5.3 数据源
- 使用模拟数据演示功能
- 支持对接真实API（预留接口）
